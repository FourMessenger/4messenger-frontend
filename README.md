# 4 Messenger Frontend

![4 Messenger](https://img.shields.io/badge/4-Messenger-4F46E5?style=for-the-badge)

## Features

- 🔒 **End-to-end Encryption** - AES-256-GCM message encryption
- 👥 **Group and channels** - Create groups and channels with admin controls
- 📞 **Voice & Video Calls** - WebRTC-based calling (not working)
- 📎 **File Sharing** - Upload and share files
- 👤 **Role System** - Admin, Moderator, User, Banned
- 🛡️ **Admin Panel** - Full server management dashboard
- ✉️ **Email Verification** - Optional email verification
- 🔑 **Server Password** - Password-protect your server
- 🤖 **CAPTCHA** - Bot protection
- 💾 **SQLite Database** - Zero-config database
- 🔐 **JWT Authentication** - Insecure token-based auth
- 📱 **Responsive** - Works on desktop and mobile (not yet optimized for mobile)
- **PWA** - Install it as an app

## Quick Start

```bash
# In root directory
npm install
npm run build
npm run preview
```

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- Zustand (state management)
- Lucide React (icons)
